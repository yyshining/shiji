# 拾迹 · 微信小程序开发中

Web 原型为作品集展示基准。小程序迁移已经开始，但页面视觉、设备兼容和端到端验收尚未全部完成；2026-10-08 暂缓后续调整。

已迁移旅程三栏、文字/照片与安排编辑、准备清单、心情日记、共享账本、图片空间、导入、助手和备份入口。云函数代码已添加；开发环境完成过一次真实 DeepSeek 文本提取联调。**公开版未配置服务，不能直接使用作者的云环境。**

## 运行

使用微信开发者工具导入仓库根目录，设置自己的 AppID。前端不需要 npm 安装。云函数依赖、集合与环境变量见 [部署说明](../cloudfunctions/README.md)。配置 `lib/config.js` 的 `cloudEnv` 后再联调云功能，禁止在前端写入模型密钥。

数据保存在当前设备；云功能是手动备份与取回，不是实时自动同步。Web 与小程序数据不互通。
