## 公开源码的配置

本仓库移除了作者的 AppID、云环境 ID、开发者工具私有配置和本机路径。使用自己的微信开发者账号与云环境配置后，才能联调对应服务。模型密钥不在客户端或仓库内；参见云函数说明。

Web 与小程序使用不同的本地存储结构。当前没有 Web ↔ 小程序数据互通，也没有多人实时协作；云备份不等于自动合并同步。
